---Reaction Tester---

The first 2 tests are reaction testers, where the user has to tap the screen in response to it going from red to green. The 3rd test involves the user to track a moving ball, and tap it accurately as many times as possible. The 4th test is an auditory response reaction speed tester, where the user has to yell into the mic as soon as they hear a beep.
