final app for assessment 4

---Reaction Tester---

The first 2 tests are reaction testers, where the user has to tap the screen in response to it going from red to green. The 3rd test involves the user to track a moving ball, and tap it accurately as many times as possible. The 4th test is an auditory response reaction speed tester, where the user has to yell into the mic as soon as they hear a beep.

---Earthquake Simulator---
create a structe and place the device on its most stable point. Upon starting the test, the phone will vibrate and simulate earthquake shocks. once completed, both acclereration and gyroscopic data is aggregated into average and peak intensity metrics. 

---Sound Pollution---
Record the decibel values of a produced sound and map the sound location. Determine the danger this sound could potentially present.

---Stretch Test---
Determine a stretch path and name, then conduct the stretch itself. Accelorometer data represents the smoothness of the movement achieved, therefore determining the users flexibility.
